# aws-cds-hackathon-2026-suppliagent
Agentic AI ordering assistant for HoReCa food distributors: restaurants order on WhatsApp with a photo of a handwritten note, voice or text; the agent matches the catalog, clarifies, confirms via email/SMS/RCS and suggests reorders. Built on Amazon Bedrock AgentCore + AWS End User Messaging for the AWS CDS Agentic AI Hackathon.
